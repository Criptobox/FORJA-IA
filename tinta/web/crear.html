      Tu proyecto en GitHub

      Subir a GitHub

      Sube tu app (todas las pantallas), un README y el archivo del proyecto en un solo commit. El token se guarda solo en este dispositivo y solo se envía a GitHub.

      Cómo conseguir el token (1 minuto)
      1. Crea antes un repositorio vacío en github.com/new.
      2. Abre Nuevo token. En «Repository access» elige Only select repositories y marca solo ese repositorio.
      3. En «Permissions → Repository» pon Contents: Read and write (y Pages: Read and write si quieres publicar la web).
      4. Pulsa «Generate token», cópialo y pégalo aquí.
